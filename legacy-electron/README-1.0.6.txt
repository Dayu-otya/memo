メモ帳 修正版 1.0.6

前回の1.0.3を基に、次の3点を修正しました。
- 本文入力欄以外（パスワード、メモ内検索、タグ、設定など）で本文用の全体ショートカットを横取りしない
- メモ内検索に「置換」「すべて置換」を追加。元の本文を対象に大文字小文字を区別せず置換
- 長文コードのコピー用本文をHTML属性へ重複保存せず、クリック時に必要な範囲だけ取得

1.0.6での追加修正
- メモ検索欄、置換欄、パスワード入力欄、通常検索欄などに入力した文字が本文へ入ってしまう問題を修正
- 本文以外の入力欄にフォーカス中は、本文エディタの再描画と入力保存処理を抑止
- この問題の再発防止テストを追加し、自動試験は73件に増加

1.0.5での梱包修正
- source/package.json と source/package-lock.json のバージョンを 1.0.5 に更新
- npm run dist は GitHub へ公開せず、ローカルの dist フォルダーだけを作成
- GitHub へ公開したい場合だけ npm run release を使用
- ZIP展開直後のフォルダー直下に package.json を配置

使い方
1. ZIPを展開します。
2. windows フォルダー内の「メモ帳.exe」を起動します。
3. 既存データを使う場合は、起動前に従来のデータをバックアップしてください。

開発・テスト・ビルドする場合
1. コマンドプロンプトまたはPowerShellで、ZIPを展開したフォルダー直下へ移動します。
   例:
   cd "C:\path\to\memo-fixed-1.0.6"
2. 初回だけ npm ci を実行します。
3. テストは npm test を実行します。
4. ローカルビルドは npm run dist を実行します。
5. GitHubへ公開する場合だけ npm run release を実行します。

このフォルダーにはソースコードと73件の自動試験を含みます。
Windows実機の日本語入力、マウス操作、実プリンター出力はこの環境では未検証です。
